# Industry Benchmark Research

面向财务 BP、经营分析与投资研究的可核验行业研究 Skill。它用于生成竞品基准、行业指标调查和行业近况研究，并将数据来源、指标口径、统计期间和可比性边界随结论一起交付。

## 适用场景

- 查询竞争对手或行业的毛利率、费用率、周转率等可复算指标。
- 生成某个行业的近期快报或深度研究报告。
- 对需要数据来源、期间、样本与可比性说明的研究任务建立一致流程。

不用于猜测未披露的私营公司数字，也不会把搜索摘要、转载或营销内容包装为可验证数据。

## 工作方式

Skill 会先确认：研究类型、用户视角（管理者、产品负责人、创业者或投资研究者），以及需要快报还是深度版。

- **行业快报**：在对话中给出 5–8 个带来源、期间与边界的要点。
- **深度版报告**：提供完整的调查边界、数据表、数据依赖、可比性检查和来源卡；在用户选择时可生成离线 HTML 简报。

对于快速变化的行业，Skill 将最近完整统计期的结构性数据与最新季度/月度景气数据分层展示，不将不同期间直接合并或比较。

## 核验原则

1. 优先使用监管披露、审计报表、公司 IR、政府统计和行业协会原始资料。
2. 标注数据等级：A（直接披露）、B（可复算）、C（代理指标）或不可用。
3. 只有 A/B 级数据进入可比结论；C 级仅用于补充观察。
4. 对集团与单品牌、不同地区/业态、年度与季度、不同收入确认方式等不可比情形明确降级或拆分。
5. 交付前检查来源、期间、口径、计算式、交叉验证及用户视角是否完整。

## 安装到 Codex

在 Codex 中使用 Skill Installer 从这个 GitHub 仓库安装，或将本目录复制到本地 skills 目录。Skill 的入口文件是根目录的 `SKILL.md`。

安装完成后，可直接提出例如：

> 我想了解动力电池行业近况，请使用这个 skill 回答。

## 使用边界

本 Skill 用于研究、经营分析和学习，不构成审计、估值、投资或合规意见。外部行业基准仅可作为第一轮参照，不能替代尽调、业务访谈或专业判断。
